# Sistema de Servicios Escolares

## Descripción del Proyecto
Este repositorio forma parte de la orquestación del proyecto "Servicios Escolares". El objetivo es gestionar el desarrollo de un sistema académico aplicando control de versiones y metodologías visuales. 

## Herramientas de Orquestación (Docs as Code)
* **Gestión Visual:** Tablero Kanban implementado en Trello.
* **Control de Versiones:** Repositorio alojado en GitHub.
* **Documentación:** Generada con LaTeX (Overleaf).
